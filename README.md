# Quantitative Methods of Economics

Репозиторий с учебными и практическими работами по количественным методам экономики. В проектах реализованы модели динамических систем, методы оптимизации, PCA, линейное программирование, фильтр Калмана, динамическое программирование и алгоритмы поиска кратчайшего пути.

Работы оформлены в виде Jupyter Notebook и содержат математическую постановку задач, программную реализацию, эксперименты и интерпретацию результатов.

## О проекте

Цель репозитория — показать применение количественных методов к экономическим, управленческим и прикладным задачам. Проекты объединяют математическое моделирование и программную реализацию на Python: от классических моделей динамики и оптимизации до алгоритмов динамического программирования и фильтрации состояний.

В рамках работ реализованы:

- модели систем обыкновенных дифференциальных уравнений;
- PCA через собственные значения и SVD;
- метод Ньютона для решения системы нелинейных уравнений;
- задачи линейного программирования и двойственные постановки;
- фильтр Калмана и RTS-сглаживание;
- алгоритм Дейкстры для задач поиска оптимального пути;
- value function iteration для модели выбора карьеры с безработицей;
- проверки свойств марковских цепей и задачи с линейными системами состояний.

## Ключевые результаты

### PCA и метод Ньютона

В `HW2_PCA_NewtonBusiness` реализованы две собственные версии PCA:

- через разложение ковариационной матрицы по собственным значениям;
- через SVD-разложение.

Результаты сопоставлены с `sklearn.PCA`. В тестовом эксперименте собственные реализации совпали с `sklearn` с точностью до численной погрешности, а качество классификации после снижения размерности составило `0.8655` для всех трёх подходов.

Также реализован универсальный метод Ньютона для поиска равновесных цен. Для задач с 2, 5 и 10 товарами метод сходится за несколько итераций и даёт решение, совпадающее с результатом `scipy.optimize.root`.

### Фильтр Калмана

В `HW4_Kalman_Timeseries_Ballistics` построены модели в state-space форме:

- временной ряд безработицы по данным `GDP_RUSSIA.csv`;
- баллистическая траектория по наблюдаемым координатам из `ДЗ3.json`.

Для временного ряда применены фильтрация и RTS-сглаживание. Для баллистической задачи реализован подбор параметров начальной скорости, угла и дисперсии шума через оптимизацию лог-правдоподобия.

### Дейкстра и динамическое программирование

В `HW5_Hanoi_Sokoban_Dijkstra` задачи представлены как графы состояний:

- для Ханойской башни найдено оптимальное решение за 7 ходов для 3 дисков;
- для Сокобана с одним ящиком найдено решение за 30 шагов;
- для Сокобана с несколькими ящиками найдено решение за 48 шагов.

### Модель выбора карьеры с безработицей

В `HW6_Career_Unemployment_Model` объединены модель выбора карьеры и модель поиска работы с вероятностью увольнения. Реализованы:

- функция ценности работающего агента;
- функция ценности безработного агента;
- резервная заработная плата;
- оптимальная политика выбора действия;
- анализ чувствительности по пособию по безработице, вероятности увольнения и коэффициенту дисконтирования.

В базовом сценарии модель сходится за 183 итерации. На сетке состояний оптимальная политика включает три действия: остаться на текущей работе, сменить работу в той же карьере или начать новую карьеру.

## Как запустить

1. Склонируйте репозиторий:

```bash
git clone https://github.com/DMalakhov1/Quantitative-methods-of-economics.git
cd Quantitative-methods-of-economics
```

2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate      # macOS / Linux
# .venv\Scripts\activate       # Windows
```

3. Установите зависимости:

```bash
pip install numpy pandas scipy matplotlib scikit-learn quantecon ortools sympy numba z3-solver autograd POT jupyter
```

4. Запустите Jupyter Notebook:

```bash
jupyter notebook
```

5. Откройте нужный ноутбук из соответствующей папки.
